
# Community Camp Game Recap Guide Agent

A prototype for community workers in the area speaking Mandrine and Cantonese, helping them organize sharing sessions after children's games and smoothly bring the discussion back to the course topic.

## Current Prototype

- Pre-set four camp scenarios: "Where Did the Trash Go?", "The Scorching Summer", "Important Water and Invisible Enemies", "First Impressions of Our Earth"; it is also possible to switch to "Import Your Own Scenario".
- YOur own scenario should inculde the whole curriculum plan，such as games and topic.
- Custom scenarios can be uploaded as PDF, DOCX, TXT, MD, or directly pasted; text extraction can be checked and edited before generation.
- Uploaded files are parsed only in memory and not written to the disk; the maximum file size is 8 MB, and the maximum number of materials characters allowed is 12,000. Scanned PDFs are not currently supported for OCR.
- Staff can select age group and sharing duration, and can add on-site observations or de-identified student quotes.
- Outputs include game entry points, opening questions, simulated student reactions, follow-up inquiries, theme reinforcement, and comprehension checks.
- When no model is configured, it runs with a demonstration sample and clearly labels "Demonstration Mode: Not Connected to Model" on the interface.
- After configuring the OpenAI-compatible interface, it is called through the server; the API key is not placed on the browser side.
- Dialogues and student inputs are not saved.

## Local Execution

Requires Python 3.10 or a newer version. Text extraction from PDF files is done using `pypdf`; DOCX, TXT, and MD files are parsed using the Python standard library.

```powershell
cd community-game-debrief-agent
python -m pip install -r requirements.txt
python server.py
```

Open the browser at `http://127.0.0.1:8000`.

## Accessing the Model

Copy `.env.example` and rename it to `.env`. Fill in a service address that supports the OpenAI Chat Completions format, the model name, and the API key. After restarting the service, the page will display that the model has been connected.

```dotenv
LLM_BASE_URL=https://api.example.com/v1
LLM_MODEL=your-model-name
LLM_API_KEY=your-api-key
```

`.env` has been added to `.gitignore`. Do not submit real keys to public repositories.

You can also set environment variables with the same name before starting the service. Environment variables take precedence over the `.env` file.

## Source Materials

The case content was compiled from the PDF of the 8th-6th August course, game supporting materials, and activity planning cases in the "Me and My Earth" camp materials. The early planning cases differ from the subsequent course files; the prototype primarily adopts the activities and themes from the daily course files. The actual explanation of the safety topic should be based on the course materials reviewed by the staff.

The student speeches generated by the model are only for discussion rehearsals and do not represent how real children would answer. Do not input children's names, contact information, or other identifiable information.
After connecting the model, the customized cases and on-site observations will be sent to the model service provider configured in the `.env`; please confirm that the course materials can be handled by this service provider and remove the children's identity information before uploading.

```text
community-game-debrief-agent/
├── activities.json   # Course examples, goals, games and organized topics
├── app.js            # Forms, requests and result presentation
├── index.html        # Page structure
├── server.py         # Static page service and model adaptation
├── styles.css        # Page style
├── .env.example      # Model configuration example, without keys
├── requirements.txt  # Dependencies for PDF text extraction
└── .gitignore
```


# 社区营会游戏复盘引导 Agent

一个面向中文区社区工作人员的辅助工具，帮助工作人员在儿童游戏后组织分享，并把讨论自然地带回课程主题。

## 当前原型

- 预置“垃圾去哪了？”“火辣辣的夏天”“重要的水和看不见的敌人”“初识我们的地球”四个营会案例；也可以切换到“导入自己的案例”。
- 自己的案例文件中为你个人书写的课程方案，其中应当包括课程游戏和课程主题。
- 自定义案例可上传 PDF、DOCX、TXT、MD，或直接粘贴材料；提取文字可在生成前检查和编辑。
- 上传文件只在内存中解析，不写入磁盘；单文件最多 8 MB，最多传入 12,000 个材料字符。扫描版 PDF 暂不支持 OCR。
- 工作人员选择年龄段、分享时长，可补充现场观察或去身份化的学生原话。
- 输出游戏切入点、开场问题、模拟学生反应、接话追问、主题回扣和理解检查。
- 未配置模型时以演示样例运行，并在界面明确标注“演示模式：未连接模型”。
- 配置 OpenAI 兼容接口后，通过服务端调用模型；API 密钥不放在浏览器端。
- 不保存对话和学生输入。

## 本地运行

需要 Python 3.10 或更新版本。PDF 文件文字提取使用 `pypdf`；DOCX、TXT 和 MD 使用 Python 标准库解析。

```powershell
cd community-game-debrief-agent
python -m pip install -r requirements.txt
python server.py
```

浏览器打开 `http://127.0.0.1:8000`。

## 接入模型

复制 `.env.example` 为 `.env`，填写一个支持 OpenAI Chat Completions 格式的服务地址、模型名称和 API 密钥。重启服务后，页面会显示模型已连接。

```dotenv
LLM_BASE_URL=https://api.example.com/v1
LLM_MODEL=your-model-name
LLM_API_KEY=your-api-key
```

`.env` 已加入 `.gitignore`。不要把真实密钥提交到公开仓库。

也可以在启动服务前设置同名环境变量。环境变量优先于 `.env` 文件。

## 资料来源

案例内容整理自“我和我的地球”营会资料中的 8 月 3–6 日课程 PDF、游戏配套材料和活动策划案。早期策划案与后续课程文件存在差异；原型优先采用各日课程文件中的活动和主题。安全主题的实际讲解应以工作人员审核后的课程材料为准。

模型生成的学生发言只是讨论预演，不代表真实儿童会这样回答。请勿输入儿童姓名、联系方式或其他可识别信息。
连接模型后，自定义案例和现场观察会发送至 `.env` 中配置的模型服务商；请确认课程材料可以交由该服务处理，并在上传前去除儿童身份信息。
