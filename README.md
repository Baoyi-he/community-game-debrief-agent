# 社区营会游戏复盘引导 Agent

一个面向社区工作人员的中文原型，帮助工作人员在儿童游戏后组织分享，并把讨论自然地带回课程主题。

## 当前原型

- 预置“垃圾去哪了？”“火辣辣的夏天”“重要的水和看不见的敌人”“初识我们的地球”四个营会案例；也可以切换到“导入自己的案例”。
- 自定义案例可上传 PDF、DOCX、TXT、MD，或直接粘贴材料；提取文字可在生成前检查和编辑。
- 上传文件只在内存中解析，不写入磁盘；单文件最多 8 MB，最多传入 12,000 个材料字符。扫描版 PDF 暂不支持 OCR。
- 工作人员选择年龄段、分享时长，可补充现场观察或去身份化的学生原话。
- 输出游戏切入点、开场问题、模拟学生反应、接话追问、主题回扣和理解检查。
- 未配置模型时以演示样例运行，并在界面明确标注“演示模式：未连接模型”。
- 配置 OpenAI 兼容接口后，通过服务端调用模型；API 密钥不放在浏览器端。
- 不保存对话和学生输入。

## 本地运行

需要 Python 3.10 或更新版本。PDF 文件文字提取使用 `pypdf`；DOCX、TXT 和 MD 使用 Python 标准库解析。

```powershell
cd community-game-debrief-agent
python -m pip install -r requirements.txt
python server.py
```

浏览器打开 `http://127.0.0.1:8000`。

## 接入模型

复制 `.env.example` 为 `.env`，填写一个支持 OpenAI Chat Completions 格式的服务地址、模型名称和 API 密钥。重启服务后，页面会显示模型已连接。

```dotenv
LLM_BASE_URL=https://api.example.com/v1
LLM_MODEL=your-model-name
LLM_API_KEY=your-api-key
```

`.env` 已加入 `.gitignore`。不要把真实密钥提交到公开仓库。

也可以在启动服务前设置同名环境变量。环境变量优先于 `.env` 文件。

## 资料来源

案例内容整理自“我和我的地球”营会资料中的 8 月 3–6 日课程 PDF、游戏配套材料和活动策划案。早期策划案与后续课程文件存在差异；原型优先采用各日课程文件中的活动和主题。安全主题的实际讲解应以工作人员审核后的课程材料为准。

模型生成的学生发言只是讨论预演，不代表真实儿童会这样回答。请勿输入儿童姓名、联系方式或其他可识别信息。
连接模型后，自定义案例和现场观察会发送至 `.env` 中配置的模型服务商；请确认课程材料可以交由该服务处理，并在上传前去除儿童身份信息。

```text
community-game-debrief-agent/
├── activities.json   # 课程案例、目标、游戏和经整理的主题依据
├── app.js            # 表单、请求与结果呈现
├── index.html        # 页面结构
├── server.py         # 静态页面服务与模型适配
├── styles.css        # 页面样式
├── .env.example      # 模型配置示例，不含密钥
├── requirements.txt  # PDF 文字提取依赖
└── .gitignore
```
